# Case study docs

Architecture notes, diagrams and test summaries for three data projects. Documentation only: there is no code, query, data, credential or business-specific name in this repository.

| Project | What it is | Portfolio case study |
|---|---|---|
| [KPI Scoring Pipeline](kpi-scoring-pipeline/) | One scoring method for every operational team, replacing manual monthly calculations | [Read](https://sunilkumar-official.github.io/projects/kpi-scoring-pipeline/) |
| [Customer Support Data Platform](customer-support-data-platform/) | A three-stage scheduled pipeline from raw support chats to relational tables, with monitoring that escalates | [Read](https://sunilkumar-official.github.io/projects/customer-support-data-platform/) |
| [Conversation Intelligence Platform](conversation-intelligence-platform/) | Deterministic facts first, then a locally run language model, evaluated against human reviewers | [Read](https://sunilkumar-official.github.io/projects/conversation-intelligence-platform/) |

Diagrams are written in Mermaid, which GitHub renders directly.

Every number here is also on the portfolio site. Where a count is approximate, it says so.
